# 交付物结构

每月交付一个文件夹和同名压缩包，文件夹名和文件名用中文：`<客户名>_Azure巡检报告_<YYYY年M月>`。

```
00_Azure巡检汇总报告_<月份>.md
01_<M>月月度成本巡检报告.md / .xlsx
02_虚拟机利用率与规格优化.md / .xlsx
03_可靠性与安全巡检报告.md + 03_可靠性与安全巡检问题清单.xlsx
04_卓越运营与性能效率巡检报告.md + 04_卓越运营与性能效率巡检问题清单.xlsx
05_同类资源配置对比报告.md + 05_同类资源配置对比明细.xlsx
charts/   所有图表 PNG（Markdown 用相对路径引用）
```

“月份”指巡检所针对的完整自然月，例如 10 月做 9 月的巡检，文件写“9月”；汇总报告和 WAF 报告按出具月份命名。两个月份在报告开头写清楚。

## 00 汇总报告

1. **总体结论**：一张表列出各项巡检的结果，例如“发现 N 项问题，其中高风险 M 项”“预计每月节省 USD x（官网列表价）”；再用 2–3 句话说明最主要的规律。
2. **需要立即处理的问题**：最多 10 条。每条写清楚问题、影响和建议；有根本原因的，按“根本原因 / 根治 / 短期”写。
3. **成本优化**：上月费用、主要变化、可量化的节省（官网列表价），以及需要客户确认后才能估算节省的项目。
4–7. **可靠性、安全、卓越运营、性能效率**：每个支柱的问题数（高/中/低）和 3–5 个要点。
8. **建议处理计划**：本周内、一个月内、一个季度内。
9. **需要客户确认或提供的信息**。
10. **后续**：下次巡检时间，以及要跟踪的事项。
- **附件**：01–05 的文件名，每份一句话说明内容。

## 01 月度成本巡检报告

章节：
- 费用总览（含需要优先关注的变化）
- 业务、服务、区域变化
- 费用变化原因
- 主要资源费用
- 资源利用率与优化建议（虚拟机、数据库和缓存、建议清单）
- 存储、备份与日志
- 月度评审与执行跟踪
- 数据范围与限制

Excel 主要工作表：
- 月度总览、图表
- 订阅/业务组/服务/区域对比
- 变化原因拆解、主要资源费用、每日费用、下月费用预测
- 建议与跟踪
- 虚拟机使用情况、数据库与缓存用量、存储、日志
- 当前闲置资源待确认、预算检查
- 数据覆盖与说明

要求：
- 汇总数字用 Excel 公式，并复算核对。
- 实际费用和分摊费用分开写。
- 公开价格标注“Azure 官网公开列表价”。

## 02 虚拟机利用率与规格优化

章节：
- 范围和结果，含当前费用和调整后的方案：按需、1 年/3 年 RI、1 年/3 年 SP
- 每台机器的建议、指标和价格
- 使用的规则
- 订阅覆盖

规则见 `cost-review.md`。交叉核对（X1–X3）时如果加了提醒，在表后用一段话说明。

## 03 可靠性与安全巡检报告 / 04 卓越运营与性能效率巡检报告

章节：
1. 需要优先处理的问题：最多 10 条，按影响排序。
2. 各支柱的检查项汇总表，列：检查项 | 高 | 中 | 低 | 涉及资源数 | 主要发现。表格上方说明“问题条数”和“涉及资源数”的区别。
3. 建议处理顺序：本周内、一个月内、一个季度内。
4. 检查范围与限制：只读、未扫描端口、环境为推断、无法读取的订阅和内容、读取日期。
- Microsoft 官方参考链接。

Excel 问题清单的列：
- 编号、支柱、检查项、严重程度
- 订阅、资源组、资源、资源类型、环境（推断）
- 发现、建议、需要客户确认
- 与同类资源的差异、根本原因、对齐标准的做法、验收标准
- 涉及资源数、涉及资源
- 负责人、客户决定、处理状态、完成日期（由客户填写）

另有两个工作表：
- “概览”：各检查项问题数 + 原生图表。
- “检查覆盖”：尝试、成功、无权限、说明。

“验收标准”一列从 M3 起加入：写清楚做到什么算整改完成。问题分两类分别计数：“已确认的问题”和“需要客户确认的事项”。

## 05 同类资源配置对比报告

章节：
- 结论
- 什么是“标准做法”和“偏差”
- 最重要的 10 项偏差
- 各类资源的标准做法与例外
- 需要修正的模板默认值
- 供应商创建的资源
- 没有内部范例的共同缺口
- 方法与局限

## 架构总览（M3 起，放在 03 报告开头或单独成节）

描述以下内容，再对照 Azure Landing Zone 的设计领域说明差距：
- 订阅和区域分布
- 主要网络结构：VNet、对等、专线和 VPN、防火墙
- 主要业务组件的承载方式

## 图表

- 用于说明变化和分布的图表，例如每日费用、增减最大的服务、各检查项问题数、告警覆盖。
- 每张图放在相关表格之后，图下一句话说明要点。
- 同时生成 PNG（Markdown 用）和 Excel 原生图表。
- 配色和标签规则见 dataviz 规范：同一图只有一个纵轴，类别颜色顺序固定，不用彩虹色。

## 打包检查

1. 包里每个文件与源文件逐字节一致；不包含 `~$` 开头的 Excel 锁文件和内部文件。
2. 所有 Markdown 通过 `quality-check`。
3. Excel 公式复算无误。
4. 压缩包用 `testzip` 检查，并与文件夹逐个比对。
5. 交叉核对（`cross-checks.md`）全部处理。
